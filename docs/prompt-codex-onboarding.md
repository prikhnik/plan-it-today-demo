Над проектом работают Claude Code (реализация), Claude Cowork (спека, вопросы, промпты) и ChatGPT (макеты и ассеты). Сейчас задача только одна: изучить проект и показать, что ты его понял. Код и документы НЕ меняй, ничего не коммить.

## Правила, которые нельзя нарушать

1. Интерфейс на украинском; в тексте для «искусственный интеллект» только «ШІ». Термин «справа» вместо «нотатка» в интерфейсе.
2. Frontend: Vite + SCSS + vanilla JS, BEM, без inline-стилей (ни `style=""`, ни JS-стили: из-за CSP), без лишних библиотек и абстракций.
3. Ассеты темы только через CSS-переменные `--img-*`; новые добавлять в `_assets.scss`.
4. Клики только через `data-nav` / `data-action` / `data-back` / `data-toast`; пользовательский текст в HTML только через `escapeHtml`.
5. Шрифт Neucha: нет знака `ʼ` (U+02BC), в текстах `’` или `'`.
6. Нельзя менять inline-скрипт темы в `index.html` без обновления sha256-хеша в `vercel.json` (сборка подскажет).
7. Команды: `corepack pnpm lint`, `format:check`, `typecheck`, `test`, `test:e2e`, `build`. Перед сдачей любой работы все проходят.
8. Не коммитить и не пушить без прямой команды автора. Новые решения не придумывать: сомнение вынести в вопрос.
9. После работы: короткий отчёт в `reports/ГГГГ-ММ-ДД-<имя>.md` (что сделано, допущения, найденные проблемы, риски), обновить «Прогресс реализации» в `CLAUDE.md` и пометки в спеке.
