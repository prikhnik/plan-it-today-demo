## 2. Новая концепция Plan It Today

Plan It Today развивается из простого планировщика с ШІ в приложение, которое подстраивается под состояние и рабочий ритм пользователя.

Основная идея — **два полноценных режима**, между которыми можно свободно переключаться.

### Режим «Спокій»

Это спокойный, уютный планировщик с уже существующим визуальным стилем: бумага, карандашные линии, рукописная типографика, карточки дел.

Его задача — помогать человеку разгрузить мысли, составить план и постепенно выполнять дела.

Основные возможности:
- Создание, редактирование и завершение дел.
- Ручное создание квестов и чеклистов.
- Шаги и существующие подпункты.
- Приоритет «Важливо».
- Прогресс выполнения.
- Планирование на сегодня и будущие даты.
- Сохранение существующей спокойной философии без давления и наказаний.

Не менять утверждённый визуальный стиль «Спокій» без отдельного согласования.

### Режим «Фокус»

Это полноценный альтернативный интерфейс для концентрации и последовательного выполнения дел.

Визуальное направление: строгий, минималистичный, структурированный, профессиональный интерфейс. Без бумажных карточек, скотча и рукописных декоративных элементов.

Точные цвета, шрифты и дизайн пока **не утверждены**.

Режим включает два состояния.

#### A. Focus Board

Главный экран режима «Фокус».

Согласованные решения:
- Единый вертикальный список дел на сегодня, а не Kanban-доска.
- Ручная сортировка задач.
- Видимый общий прогресс дня.
- Отображение приоритета и прогресса отдельных дел.
- Быстрое добавление и редактирование дел.
- Выполненные дела можно свернуть в отдельный блок.
- Основная кнопка «Почати фокус» закреплена в нижней области интерфейса.
- Кнопка запускает подготовку очереди Flow.

#### B. Flow

Отдельный полноэкранный режим выполнения.

Согласованные решения:
- Перед запуском формируется очередь задач.
- По умолчанию в неё включены все активные дела на сегодня.
- Пользователь может исключить отдельные дела и изменить порядок.
- Изменение очереди Flow **не изменяет** порядок дел на Focus Board.
- Flow показывает одно текущее дело, но **весь его чеклист**.
- Шаги можно выполнять в произвольном порядке.
- Существующие подпункты должны оставаться доступными.
- Flow не навязывает последовательное выполнение отдельных шагов.
- После завершения дела **не происходит** автоматический переход к следующему.
- Вместо этого показывается небольшой экран завершения и передышки.
- Пользователь самостоятельно нажимает «Наступна справа».
- Предусмотреть возможность перейти к следующему делу, оставив текущее незавершённым.
- Предусмотреть паузу и выход из Flow с сохранением прогресса.
- После окончания очереди показывается экран итогов сессии.

### Передышки между делами

Передышки — важная часть философии Focus Mode.

- Никаких обязательных таймеров отдыха.
- Никакого автоматического перехода.
- Пользователь сам решает, когда продолжить.
- Прогресс и очередь сохраняются.
- Время передышки не считается временем работы.

### Скрытый секундомер

Согласовано:
- Секундомер автоматически запускается вместе с Flow.
- Во время работы пользователь **не видит таймер**.
- Время учитывается для итоговой статистики.
- Паузы и передышки не включаются в чистое время фокуса.
- После завершения показывается продолжительность работы.
- Нужно продумать корректную обработку сворачивания Telegram, закрытия приложения и восстановления сессии.
- Не следует автоматически считать длительное отсутствие пользователя продуктивной работой.

### Итоги Focus-сессии

После завершения сессии показывается отдельный экран с инфографикой.

Предполагаемое содержимое:
- Количество завершённых дел.
- Количество выполненных шагов.
- Чистое время фокуса.
- Продолжительность перерывов, если её удалось корректно определить.
- Прогресс сессии.
- Список завершённых дел.
- Количество оставшихся дел.

Расширенная статистика по неделям и месяцам — возможная будущая Premium-функция.

Статистика должна быть информативной, без оценок, давления и негативных сравнений.

## 3. Общие правила двух режимов

Согласовано:
- Переключатель «Спокій / Фокус» расположен в шапке основных экранов.
- Последний выбранный режим сохраняется и восстанавливается при следующем запуске.
- Переключение доступно в любой момент вне полноэкранного Flow.
- Все дела, квесты, чеклисты, даты, приоритеты и прогресс **общие**.
- Это не два отдельных планировщика, а два представления одних данных.
- Основная навигация одинаковая в обоих режимах: «Сьогодні», «Майбутнє», «Допомога», «Налаштування».
- Внешний вид разделов может адаптироваться под текущий режим.
- Во Flow основная навигация скрыта.
- Прерванный Flow не запускается автоматически при открытии приложения.
- Вместо этого Focus Board предлагает «Продовжити фокус».
- При переключении режимов данные не теряются.

## 4. Изменение роли ШІ

Это принципиальное продуктовое решение.

Изначально ШІ был центральной частью концепции и основным основанием для подписки.

Теперь мы решили, что **ШІ не нужен для MVP и не должен быть обязательной частью продукта**.

Не предлагай автоматически переносить ШІ в Premium. Сначала проанализируй, какие существующие требования, тексты, экраны и технические решения связаны с ШІ.

Вместе со мной реши, что следует удалить из будущей спецификации, что оставить как историческую информацию, а что сохранить в качестве необязательного направления на далёкое будущее.

Не удаляй рабочий код без отдельного разрешения.

## 5. Free и Premium

Согласовано:
- Одна Premium-подписка распространяется на оба режима.
- Оба режима должны быть полноценными и полезными бесплатно.
- Базовый Flow, ручные квесты, чеклисты, передышки, секундомер и итоги сессии — бесплатные.
- Premium **не обязателен для MVP**.
- Конкретный набор Premium-функций ещё не утверждён.

Идеи для будущего Premium, **не финальные требования**:
- Дополнительные темы и оформление.
- Звуковые атмосферы.
- Шаблоны квестов.
- Повторяющиеся дела.
- Сохранённые сценарии Flow.
- Расширенная статистика.
- Дополнительные настройки рабочего пространства.
- Персонализированные варианты поощрений.

Не превращай эти идеи в обязательный MVP.

## 6. Долгосрочное развитие

Проект должен иметь возможность постепенно масштабироваться.

Возможные будущие направления:
- Привычки.
- Долгосрочные цели.
- Недельное и месячное планирование.
- История продуктивности.
- Синхронизация устройств.
- Отдельное веб- или мобильное приложение.
- Интеграции с календарями.
- Совместные задачи.

Это только потенциальная дорожная карта, не утверждённый объём разработки.

При проектировании архитектуры желательно предусмотреть расширяемость сущностей задач и Flow-сессий без преждевременного усложнения MVP.
