# Справка для Codex: что реализовано и что меняется (2026-10-09)

Для технического аудита (`docs/prompt-codex-technical-audit.md`) и для спеки двух режимов (`docs/prompt-claude-code-two-modes-spec.md`). Это сводка Cowork по состоянию на вечер 2026-10-09; источник правды: код, `docs/spec/plan-it-today.md`, `CLAUDE.md`, `AGENTS.md`, `reports/`.

## 1. Что уже реализовано (демо «Спокій»)

1. Стек: pnpm-монорепо; `apps/mini-app` (Vite + SCSS + vanilla JS, BEM, без inline-стилей из-за CSP); `packages/shared-types` (чистые бизнес-правила, `node --test`). Хранение: `localStorage` (префикс `pit:`, `schemaVersion` = 2, миграции). Бэкенда нет. Деплой: Vercel (автодеплой `main`), бот `@plan_it_today_demo_bot`.
2. Экраны: Інтро и Умови (версия условий 1.1), «Сьогодні» (Планер), «Нова справа», квест (шаги, один уровень подпунктов, прогресс), «Майбутнє» (7 дней, календарь), «Допомога» (заглушка), «Налаштування» (тема, «Швидкий доступ», история справ, данные пользователя, «Про застосунок» с меткой сборки), демо ШІ (со своими моками).
3. Правила: «Важливо» (`priority`) — важные карточки выше обычных; ручной порядок внутри группы (`Card.order`, перетаскивание, Alt+стрелки); минувшие невыполненные переходят на сегодня; завершение закрывает все шаги; история выполненных; дата-фразы (`extractNoteDate`); случайная фраза в шапке (20 штук).
4. Качество: ESLint, Prettier, `@ts-check`, 54 юнит-теста, 27 E2E (Playwright + axe + CSP), экран «Дані пошкоджені», Sentry по DSN (выключен), `track()` (no-op), CSP в `vercel.json`. Новый пользователь стартует с пустого Планера (моки отключены), старые данные были один раз очищены при переходе на схему 2.

## 2. Что решил автор (2026-10-09) по новому курсу

1. Два режима «Спокій» и «Фокус» над общими данными (подробности: `docs/prompt-claude-code-two-modes-spec.md`). Спека пока описывает только «Спокій»; обновлять её можно только после этапов вопросов и подтверждения автора.
2. ШІ больше не основа продукта и не нужен для MVP. Подписка будет для других вещей; ШІ, возможно, войдёт в подписку позже, его функционал не продуман. Демо ШІ в коде не удалять без отдельного разрешения.
3. Старая идея режима «У потоці» с оранжевым или синим акцентом снята; цвета не меняем.
4. Реализация хранения сейчас демонстрационная (`localStorage`); модель данных под режим «Фокус», сессии и статистику автор хочет продумать основательно при обновлении спеки.

## 3. Где новая концепция конфликтует с текущей спекой и кодом

1. Спека: разделы 1, 3-5 и 14 строятся вокруг ШІ-подписки; раздел 6.7 (демо ШІ); Q6, Q16; идеи 1 и 3.
2. Переключатели в шапке: уже есть светлая/тёмная тема, добавится «Спокій/Фокус» (Q57).
3. Порядок карточек: сейчас важные выше, внутри группы ручной порядок; для Focus Board нужно решить, как это соотносится с ручной сортировкой и очередью Flow (Q56).
4. Дело без шагов во Flow (Q58). Данные сессий и статистики в условиях и приватности (Q59).
5. Модель данных: нет сущностей сессии Flow, очереди, пауз, чистого времени, итогов; хранение только на устройстве, восстановление после сворачивания Telegram не продумано.
