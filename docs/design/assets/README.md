# Assets

Ассеты в стиле «олівець на папері», нарезаны из листов ChatGPT. PNG с прозрачным фоном (фон белого листа вырезан), акцент мятный `#C4EBD0`.

1. `light/`: ассеты светлой темы (графит на прозрачном фоне; на тёмном фоне не используются).
2. `dark/`: ассеты тёмной темы (мел на прозрачном фоне).
3. `textures/`: текстуры без прозрачности (бумага, оверлеи на сером #808080 для multiply/overlay, штриховки-тайлы).
4. `_sheets/`: исходные листы без обработки (белый или чёрный фон).

Размеры PNG приблизительные (~2-3x от рабочих размеров иконок), перед продом оптимизировать и при необходимости уменьшить.

Готовые листы (светлая тема): 1, 2, 3, 4, 5, 6. Тёмная тема: 1, 2, 3, 4, 5, 6 (чёрный фон вырезан по яркости, мел белый, штриховка зелёная; на светлом фоне не использовать).
