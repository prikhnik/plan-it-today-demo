## Сделано

1. **Монорепо pnpm:** `apps/mini-app`, `packages/shared-types`. `apps/api` и `apps/bot` не создавались (отдельный этап). Запуск: `corepack pnpm install`, `corepack pnpm dev`, `corepack pnpm test`, `corepack pnpm build`.
2. **Общие правила** (`packages/shared-types/src`, чистые функции, 23 юнит-теста `node --test`):
   1. `progress.js`: прогресс по верхнему уровню, шаг с подпунктами выполнен только когда выполнены все подпункты, частичный прогресс родителя, `canFinishQuest`, `canMarkNoteDone` («Готово» при 0 шагах).
   2. `dates.js`: правила раздела 7 (сьогодні / завтра / післязавтра, дни недели с «в/у» и без, «15 жовтня», «15.10», «через N дні»), подпись чипа «Сьогодні, чт 8 жовтня».
   3. `onboarding.js`: `intro | terms | done`, версии условий сравниваются численно.
   4. `types.js`: JSDoc-типы `Card` (без `tip`), `Step`, `UserProfile`.
3. **Mini App** (Vite + SCSS + vanilla JS, BEM, без inline-стилей):
   1. `core/router.js`: реестр экранов, история, `navigate(name, params, { reset, replace })`, `back()`.
   2. Делегирование кликов из `main.js`: `data-nav`, `data-action`, `data-back`, `data-toast`.
   3. `core/telegram.js`: `ready`, `expand`, отключение вертикальных свайпов, нативная `BackButton`, цвет шапки и фона под бумагу, `close()`.
   4. `core/theme.js`: тема по Telegram `colorScheme`, в браузере по `prefers-color-scheme`, реакция на смену; класс `theme-light`/`theme-dark` на `<html>`.
   5. `core/storage.js`: `localStorage` с try/catch (`pit:` префикс).
   6. Токены обеих тем в `styles/_base.scss` (`--bg-paper`, `--pencil-main`, `--pencil-muted`, `--accent-color`), ассеты темы через CSS-переменные `--img-*` (одна разметка, тема меняет только переменные).
4. **Экраны:**
   1. Онбординг: «Інтро» → «Умови користування» → Планер. Назад с Умов на Інтро (BackButton в Telegram, «Назад» в браузере). Новая версия условий → только экран Умов. Без хранилища онбординг показывается каждый запуск.
   2. Нижняя навигация (4 вкладки), верхняя панель («Закрити» / «Назад» в браузере на вложенных).
   3. Налаштування: список пунктов; «Умови користування» открывает текст только для чтения с «Назад», остальное `data-toast="Скоро"`.
   4. Планер, Майбутнє: пустые состояния (наполнение в батчах 2 и 4).
   5. Допомога: заголовок, текст, кнопка сайта (тост «Скоро», Q4), дисклеймер.
5. **Ассеты:** `scripts/prepare-assets.py` (Pillow) конвертирует `docs/design/assets` в WebP: иконки до 96 px, штриховки становятся прозрачными тайлами 280 px. 13 МБ PNG → ~2 МБ WebP в исходниках; прод-сборка целиком 0.9 МБ. Шрифт Caveat (OFL 1.1, коммерческое использование разрешено) self-hosted, кириллица + латиница, «ґ є і ї» и «ʼ» проверены.
