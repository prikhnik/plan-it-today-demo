# Фідбек демо: шість правок (2026-10-09)

Джерело: шість правок автора та затверджений план у чаті Codex. Код реалізував Codex як доповнення до Claude Code / Claude Cowork. Комітів і push не було.

## Зроблено

1. Прибрано автофокус текстових полів: Планер (холодний запуск, після умов, після додавання), Записник, додавання й редагування кроків та назви. Модальне вікно отримує фокус на панелі (`tabindex=-1`), Tab лишається всередині, Escape/Telegram Back закривають, фокус повертається до кнопки відкриття.
2. Виконана справа/квест: під «Повернути в план» сіра «Видалити квест». Підтвердження, скасування, видалення картки разом із кроками; повернення на попередній екран, зокрема історію.
3. «Налаштування → Історія справ»: усі виконані картки за днем завершення, останні дні зверху; всередині дня нові картки вище. Список із прогресом і відкриттям картки, поверненням у план та видаленням. Правило вибірки в `packages/shared-types/src/cards.js`. Виконані сьогодні лишаються в Планері до кінця дня.
4. Завершення атомарно позначає картку, всі кроки й підпункти виконаними. Старі картки зі статусом `done` нормалізуються при читанні. Без кроків прогрес `0 з 0` прихований.
5. Повний заголовок у відкритій картці без внутрішнього скролу: мінімальна висота шапки, далі висота за текстом. Нарізка `border-image` змінена: краї свитка зберігають висоту, середина росте; це усуває розтягнуту дугу поверх тексту в темній темі. На листках уже було обрізання до трьох рядків із трикрапкою — збережено.
6. «Швидкий вхід» → «Швидкий доступ» у меню та заголовку екрана. Оновлено актуальні вимоги спеки, AGENTS.md, CLAUDE.md, CLIENT_QUESTIONS.md; історичні звіти не переписувалися.

## Зберігання й допущення

1. Історія використовує існуючі `Card.status`, `completedAt`, `steps`; нових полів і зміни версії схеми немає. Нормалізація старих виконаних кроків відбувається для кожної прочитаної версії; виправлені дані зберігаються при наступній зміні store.
2. Для старих виконаних карток без `completedAt` день історії береться з `date`.
3. Повернення в план прибирає картку з історії; повторне завершення оновлює дату. Окремих записів повторного завершення немає.
4. Історія локальна на пристрої в цьому браузері, без автоочищення; «Видалити всі дані» очищає її разом з іншими даними й повторно засіває демо моками. Про це є текст на екрані історії.

## Перевірка

1. `lint`, `format:check`, `typecheck`, `test`, `build` — успішно; юніт-тести 38 + 14.
2. `test:e2e`: 20/20, включно з реальним Telegram SDK/CSP і axe для обох тем, також нового екрана історії.
3. Нові E2E: без автофокусу, старий виконаний квест із підпунктами, повернення в план/повторне завершення, скасування й підтвердження видалення з кроками, довгий заголовок на ширині 360 px в обох темах.
4. Скриншоти довгого заголовка в обох темах та історії переглянуто. Під час перевірки виправлено розтягування дуги темного свитка.
5. Старі E2E, що вимагали фокус textarea, оновлено відповідно до нового правила. Перший запуск preview у песочниці заблокував порт (`EPERM`); E2E виконано з дозволеним запуском поза песочницею.

## Межі перевірки

1. Реальну екранну клавіатуру iOS/Android усередині Telegram тут не перевіряли: автоматичні перевірки підтверджують відсутність фокусу текстових полів після переходів.
2. Синхронізації історії між пристроями немає; для цього потрібен майбутній бекенд.

## Апдейт для ChatGPT

Plan It Today, демо: автофокус усіх текстових полів прибрано. Виконаний квест можна видалити з підтвердженням. Додано «Налаштування → Історія справ» (локальна історія за днями завершення, повернення в план і видалення). Виконані квести показують повний прогрес і всі виконані підпункти; справи без кроків не показують прогрес. На листках довгі назви обрізаються до трьох рядків із трикрапкою; у відкритій картці заголовок повний, фон свитка росте за висотою тексту, прокручується весь екран. «Швидкий вхід» перейменовано на «Швидкий доступ». Нових ассетів немає. Codex доповнює Claude Code і Claude Cowork, вони лишаються в команді.
